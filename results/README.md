# Evaluation results

- `evaluation_results.json` contains all twenty generated plans (ten structured and ten raw), request metadata, and the initial automated-judge evidence.
- `PE6201_Evaluation_Results.xlsx` is the final reviewed scoring record, including the strict binary rubric, manual adjudication notes, summary statistics, and chart.

The automated judge produced a raw-baseline mean of 4.0/5. Manual adjudication found several false positives where vague language did not satisfy the written rule. The final reported means are therefore **5.0/5 structured** and **3.1/5 raw**, a **1.9-point improvement**. Keeping both artifacts makes the correction transparent rather than replacing the original evidence.
